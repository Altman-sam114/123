# v4.4 明末经济、灾荒、军饷和地方治理首片记录

## 1. 本轮目标

依据 `codex-v4.0-明末aiagent迁移总提示词.md` 的 v4.4 路线，本轮只落地明末经济首片：

- 把既有 v0.8 经济资源展示迁为民力、银两、粮草。
- 把生产 UI 和日志迁为募营兵、募精骑、募哨骑、造炮队、筹粮。
- 让明末势力完成生产后生成明末组件单位，而不是 legacy 装甲/摩托化单位。
- 让 AI 摘要能看到库存、收入、军粮维护、补员消耗和关键钱粮缺口。
- 修复默认明廷玩家在 `.humanAction` 阶段的 UI 可操作判断。

## 2. 非目标

- 不新增灾荒、瘟疫、治安、民心、腐败、拖欠军饷、将领忠诚或士气字段。
- 不新增修城、赈济、征饷、屯田或整训团练等新生产命令。
- 不改 hex / region / theater / front / deploy 权威边界。
- 不绕过 `Command.queueProduction -> RuleEngine -> EconomyRules` 的统一生产入口。
- 不删除 legacy Germany / Allies 和阿登 fallback。

## 3. 实现摘要

### 3.1 资源与生产显示

- `EconomyResources` 新增 `displaySummary` 和 `compactDisplaySummary`，统一输出民力、银两、粮草。
- `CityLevel.displayName` 改为无城镇、县镇、府州、京师/重镇。
- `ProductionKind.displayName` 改为募营兵、募精骑、募哨骑、造炮队、筹粮。
- `ProductionKind.producedUnitBaseName` 用于生成明末生产单位名。

### 3.2 经济规则

- `EconomyRules` 的 bootstrap、排产、结算、粮草短缺、自动补员、生产完成日志改为明末钱粮口径。
- 明末势力完成生产后生成明末组件单位：
  - 募营兵：步军、火器、骑兵。
  - 募精骑：旗骑、骑兵、火器。
  - 募哨骑：骑兵、步军、团练。
  - 造炮队：炮队、攻城器械、步军。
- legacy Germany / Allies 仍使用 `.infantry/.panzer/.motorized/.artillery` 工厂方法，保持旧数据兼容。

### 3.3 UI 与玩家操作阶段

- `GamePhase.displayName` 的通用阶段改为 AI 行动、玩家行动、结算；legacy 阶段显示为兼容中文。
- `GamePhase.allowsHumanCommands` 作为当前 App/UI 的可操作阶段判断，兼容 `.humanAction` 与 legacy `.alliedPlayer`。
- `AppContainer.bootstrap()` 默认把 `playerFaction` 设为明末剧本的第一个 `humanControlledFactions`，没有配置时才回退 `.allies`。
- `CommandPanelView`、`EconomyPanelView`、`HUDView`、`RegionInspectorView`、`UnitInspectorView`、`UnitTooltipView`、`EventLogView`、`RootGameView`、`WWIIHexV0MacApp` 做了钱粮和明末 UI 文案首片迁移。

### 3.4 AI 摘要

- 新增 `EconomyAISummary`，包含库存、上回合收入、军粮维护、补员消耗和民力/银两/粮草缺口。
- `AgentContext`、`AgentPromptBuilder` 和 `TurnManager.contextSummary` 纳入钱粮摘要。
- `MarshalBattlefieldSummary` 纳入 `economySummary`，schemaVersion 升到 6。
- `SimulatedMarshalLLMClient` 的 summary 和 strategicIntent 会带上钱粮摘要。

## 4. 架构边界

- 经济仍是 faction 级总账，不是地图占领权威。
- 收入仍要求 region 有真实己方控制 hex 证据，不能把中立/空控制 region 收入算给某势力。
- 生产仍由 `Command.queueProduction` 进入 `RuleEngine` 校验和执行。
- AI 只能读取钱粮摘要或输出结构化 directive，不能直接改 `economyState`、`HexTile.controller` 或 `Division.coord`。

## 5. 已知后续

- 补齐灾荒、治安、民心、腐败和拖欠军饷对收入、补员、士气、将领满意度的影响。
- 增加修城、赈济、征饷、屯田、整训团练等生产/政策命令时，仍必须走统一命令入口。
- 继续清理底层命令记录和 legacy 调试文案中的英文残留。
- 发布级 UI 仍需在 v4.6 做完整视觉和交互收口。

# v4.2 明末地图、剧本数据和 MapEditor 默认桥接记录

日期：2026-07-05

## 目标

把默认新局从阿登 legacy 数据切到第一张明末可玩数据首片，同时保留阿登 fallback 和现有 hex / region / theater / front / deployment 派生链路。

## 已落地范围

- 新增默认明末场景数据：
  - `WWIIHexV0/Data/chongzhen_1642_scenario.json`
  - `WWIIHexV0/Data/chongzhen_1642_regions.json`
- `DataLoader.loadInitialGameState()` 优先尝试 `chongzhen_1642_scenario` + `chongzhen_1642_regions`，失败后回退 `ardennes_v0_scenario` + `ardennes_v02_regions`，最后才回退旧 `GameState.initial()`。
- `ScenarioDefinition` 增加可选 `turnOrder`、`humanControlledFactions`、`aiControlledFactions`，旧 JSON 缺字段时继续 fallback `playerFaction` / `aiFaction`。
- `MapEditorGameResourceBridge` 默认读写明末 JSON。
- `MapEditorExporter` 导出明末势力文档时会从文档内势力推导 `turnOrder` / human / AI 控制数组；legacy 文档仍保留 Allies 玩家 / Germany AI 默认。
- `RegionDataSet.toRegions()` 的 owner/controller 缺省 fallback 从 `.allies` 改为 `.localNeutral`，避免无归属 region 被错误写成盟军。
- Xcode project 已把两份明末 JSON 接入 iOS 主 target 和 macOS 主游戏 target 的 Resources。

## 数据切片

默认剧本：

```text
id: chongzhen_1642_collapse
displayName: 崇祯十五年：天下裂变
map: 12x10, 120 hex
regions: 30
regionEdges: 69
supplySources: 9
objectives: 12
keyLocations: 14
initialUnits: 22
```

势力与回合：

```text
factions: ming, qing, dashun, daxi, localNeutral
turnOrder: ming -> qing -> dashun -> daxi
humanControlledFactions: ming
aiControlledFactions: qing, dashun, daxi
initialPhase: humanAction
```

当前单位说明：

- 初始单位 `name` 已用明末中文展示名。
- `templateId` 暂时复用 legacy `infantry_division`、`motorized_division`、`artillery_division`、`garrison_division`。
- 明末兵种模板、围城、粮草和战术名称迁移属于 v4.3。

## 架构边界

- 明末 JSON 仍进入 `DataLoader.loadGameState -> GameState -> RegionOccupationRules -> TheaterSystem -> FrontLineManager -> WarDeploymentManager`，不新增旁路状态。
- `HexTile.controller` 和 `Division.coord` 仍是战术权威。
- region/theater/front/deploy 仍是派生层；占领一个 hex 不会直接改整个 `regionToTheater`。
- MapEditor 仍导出 `ScenarioDefinition` 和 `RegionDataSet`，不写独立私有格式。

## 未完成项

- `ming_powers.json`、`ming_unit_templates.json`、`ming_generals.json`、`ming_terrain_rules.json` 尚未建立。
- 经济资源仍是 `manpower / industry / supplies`，生产项仍有二战语义。
- `VictoryRules` 仍有阿登 / 巴斯托涅 legacy 口径，明末胜负链后置 v4.7 / v4.8。
- 主 UI、日志、兵牌和部分 Agent 命名仍残留 WWII / Division / NATO 等 legacy 语义。
- 本记录不代表明末迁移完成，只代表 v4.2 默认数据首片和加载路径推进。

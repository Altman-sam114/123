# v4.7 明末胜负链与战役目标面板首片记录

日期：2026-07-05

本记录对应明末迁移 v4.7 的胜负链与战役目标面板首片。目标是把 `崇祯十五年：天下裂变` 的主要天下局势目标先接入 `BattleObjectiveSummary` / `VictoryRules`，并让玩家在局内看见各势力距离胜负条件还差哪些城关。

## 1. 本轮目标

- 保留 legacy 阿登胜负规则，不破坏旧测试板和旧数据 fallback。
- 对 `chongzhen_1642` 剧本启用明末胜负规则：
  - 清军控制山海关和北京，判定后金/清胜。
  - 大顺控制开封、洛阳和西安，判定大顺胜。
  - 大西控制荆州和武昌，判定大西胜。
  - 明廷在最终回合守住北京、山海关和武昌，判定明廷胜。
  - 最终回合未触发明确条件时，按 objective points 计算关键目标归属。
- 让顶部朝报令条的胜负 badge 显示简短胜负理由。
- 新增只读“目标”面板，让玩家看到四条胜负线、关键城关控制方和 objective points 领先方。
- 在目标面板加入只读战役提示，让玩家看到松锦余波、催饷安民、粮道告急、军机复盘和目标线压力等 v4.7 教程/历史 cue。
- 结束回合时将当前战役提示以去重塘报写入 `eventLog`，让历史/教程 cue 进入复盘记录。
- 保持所有判定只读取 `GameState`、`MapState` 和 objective 控制权，不从 UI 或 Agent 直接改权威状态。
- 将 `ScenarioDefinition.victoryConditions` 带入 `GameState`，让目标摘要和胜负判定优先读取剧本条件，减少明末目标硬编码。

## 2. 已完成改动

- `Objective` 新增 `points`：
  - `DataLoader` 从 `ScenarioDefinition.objectives[].points` 写入 `MapState.objectives`。
  - `ScenarioDefinition.ObjectiveDefinition` 和 `Objective` 自定义 decode，旧剧本、旧存档或旧测试数据缺少 `points` 时默认 0。
- `MapState` 新增按 objective id 查询：
  - `objective(id:)`
  - `controllerOfObjective(id:)`
- `VictoryReason` 新增明末原因和 `displayName`：
  - `mingHoldsMandateAtFinalTurn`
  - `qingBreaksPassAndCapital`
  - `dashunControlsCentralPlain`
  - `daxiControlsHuguangBase`
  - `mingHoldsMostKeyObjectivesAtFinalTurn`
  - `mingMandateCollapsedAtFinalTurn`
- `VictoryRules` 分流：
  - `scenarioId.hasPrefix("chongzhen_1642")` 时读取 `BattleObjectiveSummary` 并走明末胜负链。
  - 其他剧本继续走 legacy 阿登胜负链。
- 新增 `BattleObjectiveSummary`：
  - 优先从 `GameState.victoryConditions` 编译四条胜负线；旧存档或缺失条件时保留内置 fallback。
  - 从 `GameState` / `MapState` 派生每个目标点控制方、目标点分值和当前领先方。
  - 派生 `Cue` 列表，按当前回合、当前势力、缺粮部队、AI 指令记录和目标线进度生成最多 4 条只读战役提示。
  - `Cue` 提供塘报正文和分类，供结束回合时写入事件日志。
  - `VictoryRules` 与 UI 共用该摘要，避免胜负规则和目标展示口径分叉。
- `CommandExecutor.appendBattleCueEvents`：
  - 在 `endTurn` 中读取当前 `BattleObjectiveSummary.cues`。
  - 用 `battle-cue-<turn>-<faction>-<cue id>` 作为 `relatedRecordId` 去重。
  - 只追加 `eventLog`，不改变 hex、region、economy、victory、AI 指令或任何规则权威。
- `DataLoader.loadGameState` 现在把剧本 JSON 的 `victoryConditions` 写入 `GameState.victoryConditions`，`GameState` 旧存档解码缺失该字段时默认空数组。
- 新增 `BattleObjectivePanelView`：
  - `RootGameView` 信息面板新增“目标”tab。
  - 面板展示清破关入京、大顺据中原秦陕、大西据湖广粮区、明廷守京师关口四条目标线。
  - 面板新增“战役提示”区，用史势、政务、钱粮、军务、军机五类 cue 提醒玩家查看地图、朝廷、粮道和军机复盘。
  - 面板展示终局要冲分，让玩家能看见 objective points 归属。
- `HUDView` 胜负 badge 从只显示“某势力胜”升级为“某势力胜 · 胜负理由”。
- `RuleEngineCoreTests` 增加明末胜负规则和目标摘要语义用例，覆盖清、大顺、大西、明廷最终守线、目标线进度、分值领先方、开局提示、缺粮提示、目标线压力提示和结束回合塘报入册。

## 3. 非目标

- 不新增会修改地图、钱粮或胜负状态的历史事件系统、教程触发器、灾荒效果或多回合战役目标链；本轮战役提示只读派生，回合末只写塘报日志。
- 不新增完整政策/科技树，也不让政策直接改胜负。
- 不改变 `Command`、`ZoneDirective`、`WarCommandExecutor`、`RuleEngine` 权威链路。
- 不删除或重写 legacy 阿登胜负规则。
- 不声称完成发布级胜负体验；事件提示、教程解释、目标点击跳转、截图验收仍后续继续。

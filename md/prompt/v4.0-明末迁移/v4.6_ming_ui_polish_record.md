# v4.6 明末 UI polish 与朝廷项目记录

日期：2026-07-05

本记录对应明末迁移 v4.6 的 UI polish 首片、朝廷项目第二片、地图标识第三片、粮道线路第四片、四线项目分组第五片、粮道开关/图例第六片、舆图图例第七片、天下急势第八片和朝议争点第九片实现。目标是回应“明末要侧重中华世界局势，政策、经济、科技、军事也要重视，以及地图、部队、朝廷等界面要好看美观”，先把默认主游戏中最显眼的调试感 UI 和二战军牌继续明末化，再把朝廷面板中的政策/经济/科技/军事建议推进为轻量可执行项目，并继续清理地图上的二战/英文标识，让粮道在默认舆图中可见且可控，让朝廷项目按四线清晰呈现，让顶部图层切换更像明末战局舆图而不是 debug 控件，让“天下”面板更直观呈现当前势力、主要对手、战意和四线压力，让“朝廷”面板更直观呈现安民与征饷、火器与团练、粮道与城防之间的取舍。

## 1. 本轮目标

- 建立明末 UI 共享设计 token，统一面板圆角、间距、触控高度和朱砂/金/青瓷等色彩。
- 将朝廷面板从 `RootGameView` 拆出为独立 `CourtPanelView`，并强化奏疏、印玺、四线压力和主议/备议的视觉层级。
- 继续中文化主界面、军令、将领、单位、战报和 AI 决策面板，降低默认玩家界面的英文 debug 感。
- 将地图单位牌从 NATO APP-6 图形改为明末中文军牌徽记。
- 将主地图的地形、城池、关隘/堡寨和粮台标识继续中文化，让玩家在默认舆图上能更直观看到关城、粮源和州府节点。
- 将现有 hex 级补给路径以粮道虚线显示在默认地图上，提升“粮台、驿道、前线军粮”之间的可读性。
- 明确 UI polish 本身不绕过规则系统；朝廷项目若可执行，必须落到 `Command` / `CommandValidator` / `EconomyRules`，不能由 SwiftUI 直接改 `GameState`。
- 将朝廷项目按政策、经济、科技、军事四线分组展示，让玩家能从朝廷界面直接看出每条线的压力、关注点、成本、收益和风险。
- 给粮道虚线增加顶部开关和图例，让玩家能按需查看粮道，同时不改变 `SupplyRules` 的补给判定。
- 将地图图层名从英文 debug 口径改为舆图、州府、初划、战局、前线、布防，并用顶部图例解释城池、关隘、粮台、军牌和粮道符号。
- 强化天下局势面板，让玩家第一眼看到当前势力急势、主要敌手、战意和政策/经济/科技/军事压力，而不是只读列表。
- 强化朝廷面板的代入感，让玩家不只看到压力条和按钮，还能看到安民与征饷、火器与团练、粮道与城防三组朝议争点。

## 2. 已完成改动

- `MingDesignTokens` 新增共享 UI 常量：
  - `cornerRadius`
  - `panelPadding`
  - `sectionSpacing`
  - `compactSpacing`
  - `minimumTapSize`
  - `cinnabar` / `imperialGold` / `ink` / `jade` / `porcelainBlue`
  - `panelBackground` / `sectionBackground` / `subtleSeal` / `courtStroke`
- `CourtPanelView` 独立成文件并加入 iOS / macOS source phase：
  - 使用 `CourtStrategySummary.from(faction:state:)` 只读派生朝议。
  - 用“朝”印信、朱砂/金色描边、四线压力条、备议收益/风险和指标网格提升朝廷面板质感。
- `RootGameView`：
  - `Map Layer` 改为“图层”，`Observer` 改为“观战”，`[ INFO ]` 改为带图标的“信息”按钮。
  - 信息面板 picker 改为“面板”。
  - 移除内嵌旧 `CourtPanelView`，减少主视图膨胀。
- `GeneralCommandPanelView` / `GeneralProfileView`：
  - 用户可见文案改为将领、战区、履历、统兵风格、忠诚、军心、固守、进取等明末语境。
  - 将领印信占位和指标条使用 `MingDesignTokens`。
- `UnitInspectorView` / `UnitTooltipView`：
  - 单位详情和浮窗使用军队、坐标、兵力、粮草、退守、部署等中文口径。
  - 兵种短名改为步军、骑兵、火器、炮队、旗骑、团练、攻城等。
- `EventLogView` / `AgentPanelView`：
  - 战报标题、空态、元数据、命令结果、战区指令、错误、原始 JSON 等默认展示改为中文。
  - AI 面板的空态 fallback 改为“暂无主事”“模拟 AI”“无战术”“全局”等。
- `InfoPanelToggle` / `NewGameButton`：
  - 默认按钮改为“信息”“新局”，并保留 44pt 最小触控高度。
- `BoardScene` / `UnitNode`：
  - 空地图标题改为“明末棋策舆图”。
  - 移除 NATO APP-6 椭圆/斜线/圆形兵牌，改用中文军牌徽记：
    - `城`：攻城/炮队
    - `旗`：旗骑/重骑
    - `火`：火器支援
    - `骑`：机动部队
    - `步`：步军
  - 底部状态用兵力和 `守` / `退` 显示退守模式。
- `BaseTerrain` / `TerrainStyle` / `HexNode`：
  - `BaseTerrain.displayName` 改为平原、林地、山地、丘陵、城池、关隘/堡寨。
  - 城池 hex 增加“城”badge；关隘/堡寨 hex 增加“关”badge，旧 `FORT` 标记改为“关隘”。
  - 补给源 hex 增加按势力染色的“粮”badge，旧 `SUP A/G` 标记改为“粮台”。
  - 城池和关隘同格时下移关隘 badge 与文字，避免主地图标识直接重叠。
  - 该片只影响 SpriteKit 展示，不改变补给源控制、粮道规则、占领、经济、战区或部署层。
- `SupplyRules` / `BoardScene`：
  - `SupplyRules.supplyPath(from:to:for:in:)` 和 `SupplyRules.supplyPath(for:in:)` 复用既有补给成本、敌控、ZOC、河流和最大路径成本规则，返回只读 hex 路线。
  - `hasSupplyLine` 改为基于同一 path helper 判断，避免路径可视化与补给判定使用两套语义。
  - `BoardScene.drawSupplyRoutes` 仅在默认 hex 图层为玩家势力非毁灭部队绘制可达粮台线路；选中单位路线优先并加粗，重复公共路段去重。
  - 粮道线使用金色虚线和暗色 glow，zPosition 低于 fog、高于道路/河流，避免穿透战争迷雾或遮住军牌。
  - 该片不新增持久粮道状态、漕运资源、补给范围规则或 `GameState` 字段。
- `AppContainer` / `BoardRenderState` / `RootGameView`：
  - 新增 `showsSupplyRoutes` UI 状态，默认开启，只控制 SpriteKit 粮道绘制。
  - `BoardRenderState` 携带 `showsSupplyRoutes`；关闭后 `BoardScene.drawSupplyRoutes` 直接返回。
  - `RootGameView` 顶部地图控件新增按钮式“粮道”开关，在 hex 图层开启时显示金色虚线图例“粮道 / 可达粮台”。
  - 该片只控制 UI 展示，不改变 `SupplyRules.supplyPath`、`hasSupplyLine`、单位 `supplyState` 或任何 `GameState` 权威状态。
- `MapDisplayLayer` / `RootGameView`：
  - `MapDisplayLayer.displayName` 从 `Hex / Province / Initial / Dynamic / Front / Deploy` 改为舆图、州府、初划、战局、前线、布防。
  - `MapDisplayLayer` 新增 `systemImageName`、`legendTitle`、`legendDetail`，只服务 SwiftUI 图层说明，不改变 rawValue、Codable 兼容和 overlay 计算。
  - `RootGameView` 顶部地图控件新增“舆图”标题、当前图层说明和横向图例条。
  - hex 图层图例展示“城 / 关 / 粮 / 步”和粮道虚线；非 hex 图层展示当前 layer 的战局语义说明。
  - 该片只控制 UI 展示，不改变 `GameState`、`MapDisplayAdapter`、`MapLayerOverlayCalculator` 或任何规则权威。
- `DiplomacyPanelView` / `RootGameView`：
  - `RootGameView` 向天下面板传入 `CourtStrategySummary.from(faction:state:)` 只读朝议摘要。
  - `DiplomacyPanelView` 新增“天下急势”摘要条，展示当前势力、战局态势、主要对手、平均战意和朝议主线。
  - 天下急势用政策、经济、科技、军事四个自适应压力 badge 展示四线压力，窄面板下可自动换行。
  - “诸方势力”列表改为带势力色、阵营名义和战意进度条的行，让明廷、后金/清、大顺、大西和地方势力更易扫读。
  - 该片只读取 `DiplomacyState` 与 `CourtStrategySummary`，不新增外交关系状态，不改变 `RulerAgent`、朝廷项目执行或任何规则权威。
- `CourtPanelView` 朝议争点：
  - 在四线压力之后新增“朝议争点”区，用三组紧凑行展示安民与征饷、火器与团练、粮道与城防。
  - 每组争点只读取 `CourtStrategySummary` 中的压力值、州府数量、不稳州府、火器/炮队数量和前线数量。
  - 每组争点显示当前偏向，例如先稳地方、先补军费、先整火器、先固军伍、先保粮台或先守要冲。
  - 该片只强化朝廷面板的政策/经济/科技/军事取舍表达，不新增 `GameState` 字段，不改变 `Command.enactCourtProject`、资源校验、项目成本或 `EconomyRules`。
- `CourtProjectKind`：
  - 新增征饷、赈济安民、修城固守、整训团练、火器整备、粮台转运六类项目。
  - 每类项目声明领域、收益、风险、图标、成本和即时资源收益，覆盖政策、经济、科技、军事四线。
- `CourtProjectDomain`：
  - 新增政策、经济、科技、军事四类结构化领域。
  - 为每条线提供显示名、关注点和图标；`CourtProjectKind` 通过 `domains` / `primaryDomain` 归入四线，粮台转运继续显示为经济/军事交叉项目。
- `Command` / `CommandValidator` / `CommandExecutor`：
  - 新增 `Command.enactCourtProject(kind:)`。
  - 校验阶段要求当前 phase 允许玩家命令且当前阵营资源足够。
  - 执行阶段统一委托 `EconomyRules.enactCourtProject`，不从 UI 直接改状态。
- `EconomyRules`：
  - 征饷：消耗少量民力/粮草，换取银两，并提高最多 3 个己控州府民变、降低行政掌控。
  - 赈济安民：消耗银两/粮草，降低最多 3 个己控州府民变并提高行政掌控。
  - 修城固守：消耗民力/银两/粮草，提高最多 2 个重点己控州府 infrastructure 和 supplyValue。
  - 整训团练：消耗资源并追加 1 回合 `infantryDivision` 生产订单。
  - 火器整备：优先给最多 3 支受损火器/炮队/攻城单位恢复兵力；若没有候选单位，则追加 1 回合 `artilleryDivision` 生产订单。
  - 粮台转运：用银两换取粮草，并让最多 3 支缺粮部队恢复 supplied。
- `CourtPanelView`：
  - 在四线压力之后新增“可行项目”区，主议项目置顶。
  - 按玩家势力、观战模式、phase 和库存资源决定按钮是否可用。
  - 项目行显示领域、成本、收益、收益说明和风险说明，强化政策/经济/科技/军事取舍。
  - 第五片把“可行项目”改为“四线项目”，按政策、经济、科技、军事分组，每组展示压力值和关注点；项目按钮仍调用 `onEnactProject`，不从 View 直接改状态。

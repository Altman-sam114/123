## 1. 本轮目标

- 建立明末 UI 共享设计 token，统一面板圆角、间距、触控高度和朱砂/金/青瓷等色彩。
- 将朝廷面板从 `RootGameView` 拆出为独立 `CourtPanelView`，并强化奏疏、印玺、四线压力和主议/备议的视觉层级。
- 继续中文化主界面、军令、将领、单位、塘报战记和 AI 决策面板，降低默认玩家界面的英文 debug 感。
- 将地图单位牌从 NATO APP-6 图形改为明末中文军牌徽记。
- 将主地图的地形、城池、关隘/堡寨和粮台标识继续中文化，让玩家在默认舆图上能更直观看到关城、粮源和州府节点。
- 将现有 hex 级补给路径以粮道虚线显示在默认地图上，提升“粮台、驿道、前线军粮”之间的可读性。
- 明确 UI polish 本身不绕过规则系统；朝廷项目若可执行，必须落到 `Command` / `CommandValidator` / `EconomyRules`，不能由 SwiftUI 直接改 `GameState`。
- 将朝廷项目按政策、经济、科技、军事四线分组展示，让玩家能从朝廷界面直接看出每条线的压力、关注点、成本、收益和风险。
- 给粮道虚线增加顶部开关和图例，让玩家能按需查看粮道，同时不改变 `SupplyRules` 的补给判定。
- 将地图图层名从英文 debug 口径改为舆图、州府、初划、战局、前线、布防，并用顶部图例解释城池、关隘、粮台、军牌、军令计划和粮道符号。
- 强化军令计划在地图上的可读性，让玩家能直接看到当前回合进取/固守计划线，而不是只在将领面板里读列表。
- 强化势力归属的地图可读性，让玩家能通过“明/清/顺/西/乡”等旗号在地图军牌、部队详情和军令面板中快速识别诸方势力。
- 强化天下局势面板，让玩家第一眼看到当前势力急势、主要敌手、战意和政策/经济/科技/军事压力，而不是只读列表。
- 强化天下棋势扫读，让玩家在天下 tab 直接看到要冲分领先方、最急五线、本旬落点和各势力要冲控制数。
- 强化朝廷面板的代入感，让玩家不只看到压力条和按钮，还能看到安民与征饷、火器与团练、粮道与城防三组朝议争点。
- 强化朝廷面板的总纲扫读，让玩家在进入朝廷 tab 时先看到主议、备议、推荐项目归属和政策/经济/科技/军事四线压力。
- 强化朝廷面板的票拟扫读，让玩家能看到本旬推荐项目、四线最高压力、战役最急线、成本、收益和风险，并明确它只作只读解释，不自动执行朝廷项目。
- 强化顶部 HUD 的代入感，让玩家第一眼直接看到当前势力、回合、胜负、钱粮、营造、朝报要冲和政策/经济/科技/军事四线压力。
- 强化军令面板的代入感，让玩家能直接扫读当前势力/阶段、选中军情、兵力、粮草、退守、行动、固守/退守/补给处置和军令回执。
- 强化将领面板的代入感，让玩家能扫读防区、压力、战态、主将履历、忠诚、军心、手令干预、麾下军伍、目标和军令计划。
- 强化将领面板的军政判断，让玩家在发出固守/进取前能只读扫读政策、经济、科技、军事四线对该防区和目标州府的牵引。
- 强化 AI 决策面板的代入感，让玩家能直接扫读最高意志、决策摘要、战区指令、命令成功/驳回、异常塘报和原始 JSON。
- 强化事件日志面板的代入感，让玩家能直接扫读最近塘报、战事/粮草/州府/天下分类、最新分类、回合、势力、阶段和相关回执。
- 强化默认命令与塘报源头文案，让行军、战斗、固守、准退、补给、退守、合围消耗、回合推进和动态方面推进在默认明末 UI 中呈现中文塘报，同时保持底层命令字段稳定。
- 强化部队详情面板的代入感，让玩家能直接扫读军牌字、兵力、粮草、退守、军令战备、攻守行程察、兵种编成和驻防归属。
- 强化部队详情面板的军械火力扫读，让玩家能从既有火器、炮队、攻城器械组件、射程、兵力和粮草状态理解该军适合守关、截援、攻城还是只作辅火。
- 强化部队详情面板的要冲牵引扫读，让玩家在部队军情牌内直接看到本旬任务、目标落点、现控制方、相距格数和该军兵势，而不必切换到目标、军令或地图浮签面板。
- 强化地图选中部队浮签的代入感，让玩家不打开详情面板也能从 `UnitTooltipView` 直接扫读势力旗号、兵力条、粮草/行动/退守状态、攻守行程察指标和兵种组件 chip。
- 强化地图选中部队浮签的战局归属扫读，让玩家不打开详情面板也能从 `UnitTooltipView` 直接看到动态方面、防区和前线/纵深/驻防部署角色。
- 强化地图选中部队浮签的要冲牵引扫读，让玩家不打开目标或军令面板也能从 `UnitTooltipView` 直接看到本旬任务、目标落点和该军距目标 objective 的 hex 距离。
- 强化地图军牌的战备扫读，让玩家不点开详情面板也能从 `UnitNode` 直接看到溃散、退中、被围、缺粮和已行等优先状态。
- 强化州府详情面板的代入感，让玩家能直接扫读城关粮坊、地方治理、钱粮修正、方面/防区、目标、友敌军和当前格归属。
- 强化州府详情面板的主值判断，让玩家能先看到州府当前偏战局要冲、前线承压、城关屏障、粮台重地、工坊军械、驿道节点还是治理承压，并用政/粮/械/兵四要点联读政策、经济、科技、军事价值。
- 强化钱粮面板的代入感，让玩家能直接扫读府库库存、入账、军粮维护、补员消耗、募兵筹粮和营造队列。
- 强化钱粮面板的军饷民心扫读，让玩家能从既有账本、部队补给和地方治理摘要联读军伍、缺粮、军饷余势和民心压力，同时明确不新增真实军饷、士气、民心或灾荒系统。
- 强化钱粮面板的生产按钮说明，让玩家能直接看到募兵筹粮项目是可开工、尚缺民力/银两/粮草、待本方还是观战状态，同时明确不改变生产成本、队列或命令执行链。
- 强化朝廷项目按钮说明，让玩家能直接看到四线项目是可批、尚缺民力/银两/粮草、待本方还是观战状态，同时明确不改变朝廷项目成本、收益或命令执行链。

## 2. 已完成改动

  - `cornerRadius`
  - `panelPadding`
  - `sectionSpacing`
  - `compactSpacing`
  - `minimumTapSize`
  - `cinnabar` / `imperialGold` / `ink` / `jade` / `porcelainBlue`
  - `panelBackground` / `sectionBackground` / `subtleSeal` / `courtStroke`

  - 使用 `CourtStrategySummary.from(faction:state:)` 只读派生朝议。
  - 用“朝”印信、朱砂/金色描边、四线压力条、备议收益/风险和指标网格提升朝廷面板质感。
- `HUDView` 朝报令条：
  - 顶部 HUD 从简单标题和 grid 指标升级为朝报令条布局。
  - 顶部显示“朝”印、崇祯十五年天下裂变、当前势力、阶段、胜负状态、新局和结束回合入口。
  - 令条指标展示回合、民力、银两、粮草、营造队列和本回合入账。
  - “朝报要冲”读取 `BattleObjectiveSummary.from(state:)`，把胜负目标摘要前置到地图第一屏。
  - “朝报要冲”展示棋势领先方、最急五线和本旬任务，并在有目标落点时显示目标城关与当前控制方。
  - 朝议四线区读取 `CourtStrategySummary.from(faction:state:)`，展示政策、经济、科技、军事四线压力和主议领域。
  - 该片只读取 `GameState`、`FactionEconomyLedger`、只读 `BattleObjectiveSummary` 和只读 `CourtStrategySummary`；结束回合/新局仍通过 `onEndTurn` / `onNewGame` 回调执行，“朝报要冲”不新增按钮，不触发目标定位，不写塘报，不提交命令，不直接改 `GameState` 或任何规则权威。
- `CommandPanelView` 军令牌：
  - 军令面板从简单标题、状态和按钮列升级为军令牌布局。
  - 顶部显示“令”印、当前势力、阶段和可下令/候令/观战/敌情/已行动状态。
  - 选中军情区展示军牌字、部队名称、势力、兵种定位、兵力条、粮草、退守、行动和坐标。
  - 战术处置区展示固守、准许退守和就地补给三类按钮，配套据城关守线、保存兵力撤整、整粮草补军等明末化短说明。
  - 底部保留结束回合入口，并把最近命令反馈整理为“军令回执”。
  - 该片只读取 `selectedDivision`、`activeFaction`、`phase`、`playerFaction`、`observerModeEnabled` 和 `lastCommandMessage`；固守、准许退守、就地补给和结束回合仍通过 `RootGameView` 注入的 `AppContainer` 原有回调执行，不直接改 `GameState`、`Command`、`CommandValidator`、`RuleEngine` 或任何规则权威。
- `RootGameView`：
  - `Map Layer` 改为“图层”，`Observer` 改为“观战”，`[ INFO ]` 改为带图标的“信息”按钮。
  - 信息面板 picker 改为“面板”。
  - 移除内嵌旧 `CourtPanelView`，减少主视图膨胀。
  - 信息面板中的日志入口从“战报”改为“塘报”，和 `EventLogView` 的塘报战记保持一致。
- `GeneralCommandPanelView` / `GeneralProfileView`：
  - `GeneralCommandPanelView` 从简单标题、字段列表和按钮行升级为“将印军令”。
  - 顶部显示“将”印、候选/待授印/可议令/军心摇动/本营受压状态。
  - 主将区展示印信、姓名、官职、势力、统兵风格、履历片段、将略、忠诚、军心、手令干预和麾下数量。
  - 方面态势区展示防区、压力、战态、目标州府和目标防区势力。
  - 新增只读“帷幄四线”区，读取 `FrontZone`、`GeneralData`、`GeneralAssignment`、麾下 `Division`、目标 `RegionNode` 和本营受压状态，按政策、经济、科技、军事四格展示将心/军心、粮道/驿道、火器/攻城/工坊、防区压力/可调军伍。
  - 新增只读“督师要冲”区，读取 `RootGameView` 注入的 `BattleObjectiveSummary.from(state:)` 与 `MapState`，在将印军令内展示当前最高优先级本旬任务、目标落点、现控制方、要冲分、最近麾下军伍到 objective 的相距格数、可调营数、火器攻城和粮道状态，帮助督师/总兵面板直接联读中华世界局势、本旬军事落点和麾下兵势。
  - 麾下军伍区展示最多 5 支部队的名称、兵种图标和兵力。
  - 将令处置区保留“固守防线”和“进取州府”，仍只调用 `onHoldLine` / `onAttackRegion` 原回调。
  - 军令计划区展示已计划的回合、固守/进取意图和目标。

# v4.5 明末朝廷、政策科技与四线摘要首片记录

## 1. 本轮目标

依据 `codex-v4.0-明末aiagent迁移总提示词.md` 的 v4.5 路线，本轮只落地朝廷/政策科技首片：

- 让玩家能在信息面板看到“朝廷”入口。
- 让朝廷面板展示政策、经济、科技、军事四线压力，而不是只展示战术命令。
- 让 AI 摘要和元帅摘要读取同一套朝议建议。
- 保持朝廷摘要只读，不新增可执行政策命令，不绕过 `RuleEngine`。

## 2. 非目标

- 不新增 `CabinetState`、旧 `Minister`、旧 `StrategicDirective` 或国家内阁 JSON。
- 不新增征饷、赈济、修城、整训团练、火器整备、粮台转运等可执行命令。
- 不直接修改 `GameState`、`economyState`、`HexTile.controller`、`Division.coord`、`hexToTheater` 或 `hexToFrontZone`。
- 不接入真实 LLM、本地模型路径或 API key。
- 不做发布级美术资源、截图烟测或模拟器 UI 试玩。

## 3. 实现摘要

### 3.1 朝议摘要

- 新增 `CourtPolicyFocus`，枚举只读议题：
  - 征饷
  - 赈济安民
  - 修城固守
  - 整训团练
  - 火器整备
  - 粮台转运
- 新增 `CourtStrategySummary`，从当前 `GameState` 派生：
  - 政策压力：来自不稳州府数和平均民变。
  - 经济压力：来自银两、民力、粮草缺口和银两库存。
  - 科技压力：来自火器/炮队支撑与活跃前线数量。
  - 军事压力：来自前线压力、缺粮单位和被围单位。
- 摘要输出主议、备议、四线压力、控制州府、不稳州府、火器/炮队单位和活跃前线数。

### 3.2 UI

- `RootGameView` 的信息面板新增“朝廷”tab。
- 新增 `CourtPanelView` 私有视图，展示：
  - 当前议题。
  - 议题理由。
  - 政策、经济、科技、军事四线压力条。
  - 备议及收益/风险。
  - 州府、不稳州府、火器/炮队、前线摘要。
- 当前 UI 只读 `CourtStrategySummary.from(faction:state:)`，不写状态、不触发命令。

### 3.3 AI 摘要

- `AgentContext` 增加 `courtSummary`。
- `AgentPromptBuilder` 把朝廷四线摘要加入 prompt。
- `TurnManager.contextSummary` 加入朝议摘要。
- `MarshalBattlefieldSummary` 增加 `courtSummary`，schemaVersion 升到 8。
- `SimulatedMarshalLLMClient` 的 summary 和 strategicIntent 带上朝议摘要。

## 4. 架构边界

- `CourtStrategySummary` 是派生摘要，不是持久状态。
- 朝廷 UI、AgentContext 和 MarshalBattlefieldSummary 共用同一套派生逻辑，避免 UI 和 AI 口径分叉。
- 政策/科技真正执行时，后续必须新增 Codable directive、validator 和 executor，并最终落到 `Command` / `ZoneDirective -> WarCommandExecutor -> RuleEngine`。
- 本轮不改变 `RulerAgent` 的默认主链路地位；它仍不是默认战争 AI 主路径。

## 5. 已知后续

- 把 `CourtPolicyFocus` 升级为可执行政策/科技 directive 时，需要定义资源代价、民变/行政影响、军事收益、失败 fallback 和日志记录。
- 朝廷面板仍是首片视觉，未建立 `MingDesignTokens`，也未完成发布级奏疏/军机风格。
- Agent 决策链仍未真正形成 RulerAgent / CourtAgent / GovernorAgent / QuartermasterAgent / DiplomatAgent 多角色协作。
- 仍未新增灾荒、完整民心、军饷士气链或多回合围城链。

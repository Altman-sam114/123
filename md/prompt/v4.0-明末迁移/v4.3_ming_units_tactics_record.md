# v4.3 明末军队、战术与攻城首步记录

日期：2026-07-05

## 目标

在不绕过现有 `Command` / `ZoneDirective -> WarCommandExecutor -> RuleEngine` 管线的前提下，把 v4.2 默认明末剧本的初始单位从 legacy 阿登模板推进到明末兵种模板，并补上第一批可解释的战术、火器和攻城规则入口。

## 已落地范围

- `ComponentType` 保留 legacy `tank`、`motorizedInfantry`、`infantry`、`artillery`，新增 `cavalry`、`firearm`、`bannerCavalry`、`militia`、`siegeEngine`。
- `Division` 增加通用 helper：`isMobileUnit`、`hasFireSupport`、`isSiegeCapable`；AI 战术筛选和执行器不再只识别 motorized / tank。
- `unit_templates.json` 追加首批明末模板：
  - 明廷：`ming_banner_cavalry`、`ming_garrison`、`ming_line_infantry`
  - 后金/清：`qing_banner_cavalry`、`qing_artillery_train`、`qing_vanguard`
  - 大顺 / 大西：`dashun_camp`、`dashun_raiders`、`daxi_camp`、`daxi_raiders`
  - 地方：`local_tuanlian`
- `chongzhen_1642_scenario.json` 的 22 个初始单位已切到上述明末模板；legacy 阿登模板仍保留给 fallback 数据。
- `DataLoader.makeDivisions` 读取模板 `maxHP`，并校验模板组件是否能映射到 `ComponentType`。
- `CombatRules` 增加首步规则：
  - 攻击 city / fortress 时，炮队或攻城器械单位获得攻城加成。
  - 具备火器 / 炮队 / 攻城器械的单位进行非邻接攻击时获得小幅火力支援加成。
- `EconomyState` / `EconomyRules` 的单位分类和补员 / upkeep 权重开始识别骑兵、旗骑、火器和攻城器械。
- `TacticName.displayName` 增加明末展示名：正攻、疾袭、突骑破阵、破围、合围、火器压制、佯攻、流动作战、固守、诱敌退守、层层设防、死守城关。
- `AgentPanelView` 的 directive 摘要优先显示明末战术名。
- MapEditor 默认单位模板和默认部署阵营切到明末口径，并保留 legacy 德 / 盟模板选项。

## 架构边界

- `Division` 仍作为源码兼容名保留，当前只迁移玩家可见模板、组件和战术语义。
- 不新增独立 morale、payStatus、grainCarry 或多回合 siege state。
- 粮草仍沿用现有 `SupplyRules` / `SupplyState`；完整粮道、军饷、民心和地方治理后置 v4.4。
- 不改 `CommandValidator` / `RuleEngine` 权威边界；玩家和 AI 行动仍必须走统一规则系统。
- 不删除阿登 legacy 数据和 legacy unit template。

## 未完成项

- 主 UI、tooltip、兵牌和经济面板仍有部分英文 / legacy 术语，发布级明末 UI 后置 v4.6。
- 没有实现多回合围城状态、围城日志链、粮草路线 UI 或军饷士气字段。
- `VictoryRules` 仍保留阿登 / 巴斯托涅 legacy fallback，明末胜负链后置 v4.7 / v4.8。
- 本轮不新增本机 XCTest、Probe、Smoke、模拟器或 xcodebuild 验证。
